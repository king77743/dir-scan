# 🔍 Dir-Scaner v1.0

Dir-Scaner — это консольный инструмент на Python для проведения аудита безопасности файловой системы. Скрипт предназначен для рекурсивного поиска лог-файлов и обнаружения признаков манипуляции данными (Anti-forensics).

## 🛡️ Функционал
* Рекурсивное сканирование: Глубокий обход директорий с использованием библиотеки os.
* Детектирование аномалий: Автоматическое выявление пустых (0 байт) или подозрительно малых логов, что может указывать на зачистку следов присутствия в системе.
* Анализ метаданных: Сбор точного времени изменения и размера каждого файла.
* Цветовая индикация: Визуальные алерты для быстрой навигации по отчету:
  * 💀 Критично: Файл полностью очищен.
  * ⚠️ Подозрительно: Файл имеет аномально низкий вес.
  * ✅ Чисто: Файл прошел базовую проверку.
* Отказоустойчивость: Корректная обработка ошибок доступа (PermissionError) и прерывания пользователем (Ctrl+C).
